# People Analytics Dashboard

![image alt](https://github.com/namrataojha01/People-Analytics/blob/main/Screenshot%202026-09-07%20031252.png?raw=true)


## Overview
End-to-end HR analytics project analyzing 100,000 employee records 
to uncover insights on attrition, performance, and workforce trends.

## Tools Used
- Python | Pandas | Matplotlib | Seaborn — Data Cleaning & EDA
- Power BI | DAX | Power Query — Dashboard & Visualization

## Features Engineered
- Age Group, Tenure Group, Performance Category
- Salary Band, Attrition Label, Hire Year

## Key Insights
- Overall Attrition Rate: 10%
- Junior employees (0-1 yr) have highest attrition risk
- IT & Engineering lead in performance scores
- PhD holders show highest average performance
- Salary growth directly correlates with promotions

## Dashboard Pages
1. **Overview** — KPIs, Attrition Trend, Gender & Tenure Distribution
2. **Performance** — Performance by Dept, Training vs Performance, Salary Analysis
3. **Attrition Analysis** — Attrition by Dept, Age, Job Title & Satisfaction

## Dataset
Source: Maven Analytics — Employee Performance & Productivity Dataset
Records: 100,000 | Columns: 20 | Period: 2014–2024
